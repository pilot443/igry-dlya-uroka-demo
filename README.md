# Игры для урока: демо-прототип

Демонстрационный прототип модуля для учителей: каталог из трёх игровых форматов («Правда / ложь», «Заполни пропуск», «Найди соответствие»), редактор заданий, «Мои игры» и полноэкранный режим показа. Интерфейс на русском и казахском.

Демо работает только в браузере: игры сохраняются в localStorage вашего браузера, никаких данных на сервер не отправляется. Казахские тексты черновые и требуют проверки носителем языка.

Открыть: https://pilot443.github.io/igry-dlya-uroka-demo/

Стек: Nuxt 3, Vue 3, TypeScript, Pinia. В репозитории лежит только готовая статическая сборка; исходный код с тестами (Vitest, Playwright) передаётся по запросу.

# Lesson games: demo prototype

A demo prototype of a teacher-facing module: a catalogue of three game formats (true/false, fill in the blank, match the pairs), a task editor, "My games" and a full-screen presentation mode. The interface is available in Russian and Kazakh.

The demo runs entirely in the browser: games are stored in your browser's localStorage and nothing is sent to a server. Kazakh texts are drafts and need a native-speaker review.

Open: https://pilot443.github.io/igry-dlya-uroka-demo/

Stack: Nuxt 3, Vue 3, TypeScript, Pinia. This repository contains only the built static site; the source code with tests is available on request.
